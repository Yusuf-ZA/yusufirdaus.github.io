# Yusuf Firdaus — Football Portfolio

Website pribadi bertema sepak bola dengan latar stadion, desain gelap dengan aksen kuning, dan ilustrasi jersey nomor punggung 17.

## Isi
- `index.html` — struktur website
- `style.css` — tampilan dan layout responsif
- `script.js` — menu navigasi mobile dan tahun otomatis

## Publikasikan dengan GitHub Pages
1. Buat repository bernama `yusufirdaus.github.io` pada akun GitHub `yusufirdaus`.
2. Ekstrak ZIP, lalu upload `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu klik **Save**.
5. Tunggu hingga GitHub Pages selesai menerbitkan website.
6. Buka `https://yusufirdaus.github.io`.

Foto latar dan foto galeri dimuat dari Unsplash, sehingga koneksi internet diperlukan. Jersey nomor 17 dibuat dengan CSS dan tidak memerlukan file gambar terpisah. Website ini tidak menggunakan musik.
